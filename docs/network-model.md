# Modèle réseau

Statut : à concevoir (étape 0).

À définir : topologie du laboratoire, isolation, visibilité effective du sensor, réseaux supervisé et de management, ports exposés et capabilities nécessaires.

Critère indispensable : démontrer que le sensor observe réellement le trafic entre le générateur et la cible. Le simple partage d’un réseau Docker ne constitue pas cette preuve.
